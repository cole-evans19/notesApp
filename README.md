# Notes App

The project is a notes app in which the user can add notes to a database and edit the notes. 

## Functionality 

The following **required** functionality is completed:

* [ ] User sees a recycler view of their notes. 
* [ ] User can add notes, edit notes, and login

The following **extensions** are implemented:

* firebase

## Notes

I really struggled with this project. I'm not exactly sure how to correctly link the database to the actual notes, and I was really struggling to fetch the data.
However, I think I did a good job restructuring the project and implementing the login.
